# 💣 マインスイーパー

ブラウザですぐに遊べるマインスイーパーです。HTML・CSS・JavaScript をすべて `index.html` 1枚にまとめていて、外部ライブラリは使っていません。

**▶ 遊ぶ：https://ogitet.github.io/minesweeper/**

## 特徴

- **3つの難易度**：初級（9×9・地雷10個）、中級（16×16・40個）、上級（30×16・99個）
- **初手は必ず安全**：最初に開いたマスとその周囲には地雷が置かれません
- **まとめて開く**：数字マスをクリックすると、周りの旗の数が数字と同じときに残りのマスを一括で開きます
- **効果音**：Web Audio API でその場で合成しています。🔊 ボタンで消音できます
- **ランキング**：難易度ごとに上位5件のクリアタイム（0.01秒単位）と日付を記録します
- **スマホ対応**：長押しで旗を立てられます。「旗モード」に切り替えると、タップで旗を立てられます
- **ダークモード対応**

## 操作方法

| 操作 | PC | スマホ |
|---|---|---|
| マスを開く | クリック | タップ |
| 旗を立てる／外す | 右クリック | 長押し、または旗モードでタップ |
| 周りをまとめて開く | 数字マスをクリック | 数字マスをタップ |
| リスタート | 🙂 ボタン | 🙂 ボタン |

## ローカルで動かす

リポジトリを取得して `index.html` をブラウザで開くだけで遊べます。サーバーは必要ありません。

```sh
git clone https://github.com/ogitet/minesweeper.git
open minesweeper/index.html
```

## データの保存について

ランキングと消音の設定は、ブラウザの localStorage に保存しています。サーバーには何も送りません。別のブラウザやシークレットウィンドウでは記録は引き継がれません。
